# 레퍼런스

색온도와 브랜드는 가져오지 않는다. **편집 문법(여백 리듬, 섹션 전환, 타이포 위계)만** 참고한다.
두 곳 다 카카오임팩트 계열이지만 이 프로젝트와는 무관하다 — CLAUDE.md 7장 참조.

## kakao-impact.png
- 볼 것: 섹션마다 배경색을 통째로 바꿔 리듬을 만드는 방식, 큰 숫자 타일(`숫자로 보는`)의 위계, 연도 타임라인의 가로 스크롤 처리.
- 가져오지 않을 것: 노랑/검정 대비, 캐릭터 일러스트, 뉴스·자료실 같은 축적형 메뉴.

## sai-digital-world.png
- 볼 것: 밝은 배경 위 둥근 카드, 성과 수치 그리드 배치, 하단 CTA 블록의 여백.
- 가져오지 않을 것: 실적 수치 자체(우리는 실적이 없다), 현장 사진 중심 구성.
- `docs/images/home-hero-reference.png`와 같은 파일. 웹기획안 A-1 히어로 레퍼런스로도 쓰인다.
